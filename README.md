# Abhishek Soni — Developer Portfolio

This is a responsive single-page portfolio website designed for use on a resume, LinkedIn, GitHub Pages, Netlify, or Vercel.

## Before publishing

Replace these placeholders in `index.html`:

- `YOUR-LINKEDIN` → your LinkedIn username / full profile URL
- `YOUR-GITHUB` → your GitHub username / full profile URL
- `resume.pdf` → put your current resume PDF in this same folder
- Food Rescue Live GitHub URL → replace with the exact repository URL
- Live Demo URL → replace when you deploy the project

## Recommended publishing method: GitHub Pages

1. Create a public GitHub repository named `portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and your `resume.pdf`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`.
6. Save.
7. GitHub will provide a public URL such as:
   `https://YOUR-GITHUB.github.io/portfolio/`

## Add the portfolio to your resume

Use a contact line like:

`Portfolio: https://YOUR-GITHUB.github.io/portfolio/`

## Add the portfolio to LinkedIn

Add it in:
- Contact info → Website
- Featured section → Add a link
- About section → include the URL near the end
